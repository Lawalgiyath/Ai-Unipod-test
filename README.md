# AI UniPod Lagos Website

Nigeria's first AI-themed University Innovation Pod at the University of Lagos, powered by UNDP's Timbuktoo Initiative.

## 🚀 Quick Start

1. **Open the website**: Navigate to `frontend/index.html` and open in your browser
2. **That's it!** The site works immediately with mock data (no backend setup required)

## 📁 Project Structure

```
frontend/     - All website files (HTML, CSS, JS, images)
docs/         - Documentation and setup guides
scripts/      - Utility scripts for deployment
```

## 🎨 Design System

- **Primary Color**: #1E84C2 (UniPods Blue)
- **Secondary Color**: #FFDE59 (UniPods Yellow)  
- **Typography**: Ubuntu (headlines), Proxima Nova (body text)
- **Design**: Material Design principles with fluid animations

## 🔧 Configuration

The site uses **Mock API** by default (no setup needed). To switch to Supabase:

1. See `docs/SUPABASE_SETUP.md` for database setup
2. Edit `frontend/js/config.js` to enable Supabase
3. Run `scripts/switch-to-supabase.sh` (or `.bat` on Windows)
