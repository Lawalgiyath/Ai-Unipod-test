OPTIONAL: Use Your Own Logo Image
===================================

If you want to use your own UNILAG logo file:

1. Save your UNILAG logo as: images/unilag-logo.png
   (Create 'images' folder if it doesn't exist)

2. In index.html, change line ~92 from:
   src="https://upload.wikimedia.org/wikipedia/en/4/4b/University_of_Lagos_logo.png"
   
   To:
   src="images/unilag-logo.png"

3. Repeat for other HTML files (about.html, news.html, etc.)

LOGO SPECIFICATIONS:
====================

Recommended:
- Format: PNG with transparent background
- Size: 400x400px or higher
- Aspect ratio: Square or close to square
- File size: Under 100KB

The CSS will automatically resize it to fit (32px height).
