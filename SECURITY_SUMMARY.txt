  🚀 QUICK START (3 STEPS)
═══════════════════════════════════════════════════════════════

STEP 1: Generate Credentials
  Windows: scripts\generate-credentials.bat
  Linux/Mac: bash scripts/generate-credentials.sh

STEP 2: Configure Netlify
  1. Go to Netlify Dashboard
  2. Site Settings → Environment Variables
  3. Add generated credentials:
     - ADMIN_EMAIL
     - ADMIN_PASSWORD_HASH
     - JWT_SECRET
     - SUPABASE_URL
     - SUPABASE_ANON_KEY
     - SUPABASE_SERVICE_KEY

STEP 3: Deploy
  netlify deploy --prod
